Agent 项目面试，面试官真正想问的三件事

Lau · 2026-11-17 · 面试复盘

简历上的 Agent 项目越来越多，但面试官真正想区分的，从来不是「你做没做过 Agent」，而是三件更具体的事。这三件事，恰好也是我所有项目围绕的核心。

第一件：它记住的东西是不是真的

当面试官问「你的 Agent 会不会记错」，他不是在考向量库的用法，而是在问事实源设计。我的回答是 cross-border-crm：本地 SQL 做唯一权威，Mem0 只做排序不做事实源，远端命中过三重核对，服务异常回退本地并标明覆盖范围。

第二件：它动手之前谁说了算

问「Agent 会不会乱发消息、乱写数据」，考的是授权边界。我的回答有两层：平台侧用 PreToolUse 集中拦截 + safe/ask/allow-all；业务侧让专家只读、父流程做唯一写者，所有外发动作过独立授权闸门。

第三件：它做完了凭什么说做对了

问「你凭什么说它做对了」，考的是可评测性。我的回答是分层评测：先结构断言，再语义 Judge，区分引用未观察、字段矛盾、语义待复核三类问题，并把失败样本做回归，让「越用越准」有据可查。

一句话总结

能把这三种追问落到具体设计和证据上的候选人，比「会调 LangGraph」稀缺得多。面试的本质不是展示你用了多少工具，而是证明你对 Agent 的不可靠有清醒的工程应对。
